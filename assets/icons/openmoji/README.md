# OpenMoji pictures (subset)

Colour pictures used as noun and word pictures (`emoji:<hexcode>`, see
`src/Content/NounPictures.php`). Only the pictures the courses use are
bundled; one SVG per emoji, named by its hex code (e.g. `1F44B.svg`).

All emojis designed by **OpenMoji – the open-source emoji and icon project**
(https://openmoji.org). License: **CC BY-SA 4.0** (`LICENSE.txt`). Version
15.1.0, from the npm package `openmoji` (`color/svg/`). The files are
unchanged.

Pages that show these pictures carry the credit line "Bilder: OpenMoji
(CC BY-SA 4.0)".
